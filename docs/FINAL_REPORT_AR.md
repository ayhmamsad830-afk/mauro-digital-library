# تقرير الإنجاز النهائي — مكتبة «مُعِين خيري» (MAURO)

**التاريخ:** 2026-11-06 · **النطاق:** موقع ويب فقط، ثنائي اللغة (العربية افتراضيًا + الإنجليزية)، RTL/LTR، وضع فاتح/داكن، PHP 8.4 (يعمل أيضًا على 8.3)، MVC حقيقي، MySQL/InnoDB، ‏PDO مع استعلامات مُعدّة، JavaScript أصلي بلا أطر.

> هذا التقرير يفصل بوضوح بين ما **تم تنفيذه واختباره فعليًا** وما هو **محجوب لأسباب خارجية** (موارد أو بيانات اعتماد غير متاحة). لم يُعلَن أي اختبار غير منفَّذ على أنه ناجح.

## 2. ما تم تنفيذه واختباره

### 2.1 الأساس (المرحلة 1)
- نواة MVC خاصة: موجّه مسارات بقيود regex، طلب/استجابة، عرض، إعدادات و`.env`، اتصال PDO كسول، جلسات آمنة (strict mode، ‏HttpOnly، ‏SameSite=Lax، ‏Secure على HTTPS)، CSRF عام، ترويسات أمان، معالجة أخطاء وسجلات، صفحات 404/500/503، مُرحّل قواعد بيانات، أداة سطر أوامر.
- 9 ملفات ترحيل MySQL (‏0001–0009) + مخطط SQLite مطابق يُتحقق من تطابقه آليًا.

### 2.2 الهوية والتصميم (المرحلة 2)
- الشعار الرسمي محفوظ **بايتًا ببايت** (`public/assets/images/brand/logo.png`) مع النص بجانبه، وأيقونات الموقع على لوحة مربعة دون قص.
- نظام تصميم كامل، العربية/الإنجليزية مع تبديل الاتجاه، الوضع الداكن المحفوظ، قائمة جوال، جميع الصفحات بلا تمرير أفقي على 375/768/1280 بكسل.

### 2.3 المكتبة (المرحلة 3)
- الفهرس، البحث مع توحيد العربية (الهمزات، التاء المربوطة، التشكيل…)، التصفية والترتيب والترقيم داخل SQL، التصنيفات (مع الفرعية)، المؤلفون، الأحدث، الأكثر قراءة، صفحة الكتاب والكتب المشابهة.
- **سياسة الأعضاء:** كتب «للأعضاء فقط» مخفية تمامًا (404) عن الزوار في كل مكان: الفهرس، البحث، العدّادات، المشابهة، المؤلفون، التفاصيل، القارئ، الصور، الأغلفة وخريطة الموقع.
- إدارة الكتب والتصنيفات والمؤلفين بدورة حياة كاملة (مسودة/نشر/إلغاء نشر/أرشفة/استعادة) مع شروط النشر (حقوق + ملف جاهز).

### 2.4 القارئ المحمي (المرحلة 4) — البنية الحرجة محفوظة كما طُلب
- ملف PDF الأصلي **لا يُرسل إلى المتصفح أبدًا**؛ لا PDF.js؛ الأصول خارج `public/` بأسماء عشوائية.
- تحقق الرفع: الحجم، التوقيع، finfo، ‏`pdfinfo`، رفض الملفات المشفرة، حد الصفحات.
- تحويل على الخادم (Poppler → WebP) مع بوابة اكتمال وإصدارات؛ لا يُفعَّل الإصدار الجديد إلا بعد اكتمال كل صفحاته.
- تسليم صفحة بصفحة بروابط موقّعة قصيرة العمر (5 دقائق) مربوطة بالجلسة، مع إعادة فحص الظهور والعضوية في **كل** طلب.
- علامة مائية شخصية (معرّف مستعار + تاريخ) **مدموجة في البكسلات**.
- لا أزرار تنزيل أو طباعة، منع التحديد والنسخ العادي، إخفاء القارئ عند الطباعة.
- **تنبيه صريح:** لا يمكن لأي موقع منع لقطات الشاشة أو التصوير؛ الحماية هنا ردع وتتبّع، لا DRM.

### 2.5 الحسابات والأعضاء (المرحلة 5)
- تسجيل الدخول بـ Google (GIS) مع **تحقق كامل على الخادم**: RS256 فقط، توقيع JWKS، ‏`iss`/`aud`/`exp`/`iat`، ‏nonce لكل جلسة يُستهلك مرة واحدة، بريد موثّق، عدم دمج الحسابات بالبريد، رفض الحسابات الموقوفة، سجل تدقيق.
- منطقة العضو: المفضلة، الإشارات المرجعية، سجل القراءة، المراجعات والتقييم (مع إعادة حساب المتوسط)، استيراد تقدّم الزائر بموافقة صريحة، حفظ اللغة المفضلة.

### 2.6 لوحة الإدارة الكاملة (المرحلة 5)
- المستخدمون (بحث، إيقاف/تفعيل، منح/سحب صلاحية المدير؛ لا تعديل للذات، وحماية آخر مدير).
- مراجعة التعليقات (إخفاء/إعادة نشر مع إعادة حساب التقييم).
- التحليلات من بيانات القراءة الحقيقية فقط (لا أرقام مختلقة): الجلسات يوميًا، الأعضاء/الزوار، الصفحات، الكتب الأكثر قراءة، الأجهزة.
- سجل النشاط، الإعدادات (عدد الكتب في الصفحة، الكتاب المميز، بريد التواصل — مربوطة فعليًا بالموقع)، نظرة على ملفات PDF وحالات المعالجة.
- رفع الأغلفة وصور المؤلفين: فحص النوع والأبعاد ثم **إعادة ترميز إلى WebP** (يُسقط أي حمولة مخفية) وتخزين خاص، مع احترام سياسة الظهور عند العرض.

### 2.7 الأمان والجودة (المرحلة 6)
- ترويسات أمان على كل أنواع الاستجابات، CSP صارمة بلا `unsafe-inline`/`unsafe-eval`، إزالة ترويسة إصدار PHP.
- فحص آلي (بالمحلل اللغوي لـ PHP) لكل مخرجات القوالب ضد XSS.
- تحديد المعدل: Google، البحث، المراجعات، التقدّم، القارئ، رفع الإدارة.
- عنوان IP الحقيقي من الوكلاء الموثوقين فقط، منع إعادة التوجيه المفتوح، صفحات خطأ لا تكشف تفاصيل داخلية، `sitemap.xml` بالكتب العامة فقط مهما كان الطالب.
- فحص وصولية آلي في كل صفحة يزورها المتصفح (تسميات الحقول، النص البديل، أسماء الأزرار، عنوان h1 واحد، معرّفات فريدة، اللغة/الاتجاه).
- التفاصيل والربط بالاختبارات: `docs/SECURITY.md`.

### 2.8 تجهيز النشر (المرحلة 7)
- `deploy/`: إعداد Nginx، ‏Apache، ‏php.ini للإنتاج، ‏crontab. ملف `.htaccess` في الجذر كشبكة أمان إذا رُفع المشروع كاملًا إلى جذر الويب.
- `env:check` موسّع: PHP والإضافات والحدود، التخزين خارج الجذر، اختبار تحويل PDF حقيقي، ‏APP_KEY/DEBUG/URL، الكوكي الآمن، إطفاء الوضع التجريبي، الاتصال بقاعدة البيانات والترحيلات المعلقة، توفر mysqldump.
- النسخ الاحتياطي: `backup:run` (قاعدة البيانات + الأصول الخاصة مع ملفات sha256 وحذف القديم)، ‏`backup:verify`، و`render:rebuild` لإعادة توليد الصفحات بعد الاستعادة.
- قائمة تحقق إنتاج من 10 خطوات في `docs/DEPLOYMENT.md`.

## 3. المحجوب لأسباب خارجية (لم يُختبر ولا يُدّعى نجاحه)

| البند | السبب | ما المطلوب لإكماله |
|---|---|---|
| **MySQL الحقيقي** (32 اختبارًا + تطبيق الترحيلات) | لا خادم MySQL ولا بيانات اعتماد في بيئة البناء (`Connection refused`) | بيانات `mauro_library_dev` و`mauro_library_test` ثم تنفيذ الخطوات في `docs/MYSQL_VERIFICATION.md` (المتوقع: 32 ناجحًا) |
| **النسخ الاحتياطي لقاعدة البيانات واستعادتها** | يعتمد على MySQL و`mysqldump` | تشغيل `backup:run` ثم تجربة استعادة على نسخة تجريبية |
| **تسجيل الدخول الحي بـ Google** | لا يوجد `GOOGLE_CLIENT_ID` ولا نطاق HTTPS معتمد | إنشاء OAuth Client من نوع Web في Google Cloud، إضافة النطاق إلى Authorized JavaScript origins، وضع المعرّف في `.env` (التحقق من الرموز مختبر برمفتاح RSA محلي يحاكي Google) |
| **خادم الإنتاج** | لا تفويض ولا بيانات خادم | تشغيل `env:check` على الخادم، رفع حدود الرفع، تثبيت Poppler والـ cron، اتباع قائمة التحقق |
| **PHP 8.4 تحديدًا** | بيئة البناء فيها PHP 8.3.6 | الشيفرة متوافقة مع 8.3 و8.4؛ يُعاد تشغيل الاختبارات على 8.4 في الخادم |

ما يغطي هذه الفجوة جزئيًا: جميع منطق الاستعلامات مختبر على قاعدة SQLite مطابقة للمخطط بنفس اختبارات العقد، لكن ذلك **لا يثبت** السلوك الخاص بـ MySQL (InnoDB، الترتيب utf8mb4، الاستعلامات المعدّة الأصلية).

## 4. كيف تُعاد الاختبارات

```bash
php tests/run.php                                   # كل الاختبارات (تشمل المتصفح إن توفر Node/Playwright)
E2E_SHOTS=/tmp/shots php tests/run.php RealBrowser  # القارئ + الإدارة + الأعضاء في متصفح حقيقي
php tests/run.php MySql                             # بعد توفير DB_TEST_* (حاليًا: 32 متخطّى — محجوب)
php bin/console env:check                           # جاهزية الخادم
```

## 5. محتوى الأرشيف
الأرشيف النهائي يحتوي الشيفرة الكاملة والوثائق والاختبارات وملفات النشر، **ويستبعد**: `.env` (أسرار)، ‏`.git`، ومحتوى التشغيل في `storage/` (الجلسات، السجلات، الذاكرة المؤقتة، النسخ الاحتياطية، ملفات PDF والصفحات الخاصة) مع الإبقاء على بنية المجلدات وملفات الحماية فيها.

## 6. الخطوات التالية المقترحة
1. توفير بيانات MySQL ← تشغيل `migrate` واختبارات MySQL وتسجيل النتيجة في `docs/MYSQL_VERIFICATION.md`.
2. إعداد Google OAuth على النطاق النهائي ← أول تسجيل دخول ثم `user:promote`.
3. النشر على الخادم وفق `docs/DEPLOYMENT.md` §9، ورفع كتاب مرخّص حقيقي للتحقق النهائي.
4. مراجعة قانونية لنصوص الخصوصية والشروط وحقوق النشر (هي مسودات موسومة بذلك في الموقع).
